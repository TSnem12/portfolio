# Tasneem Mohamed — Developer Portfolio

A responsive developer portfolio showcasing my backend projects, skills, education, and contact links.

🔗 **Live site:** https://tsnem12.github.io/portfolio/

## Features

- Mobile-first responsive layout using Flexbox and CSS Grid
- Dark / light theme toggle, saved in `localStorage`
- Smooth-scrolling navigation
- Hamburger menu on mobile
- Project modal popups with details and GitHub links
- Semantic HTML5 structure (header, nav, main, sections, footer)
- Downloadable CV
- Deployed on GitHub Pages


## Tech Stack

- HTML5
- CSS3 (custom properties, Flexbox, Grid, media queries)
- JavaScript 
- GitHub Pages
